# Syntara AI — Frontend SaaS Landing Page

> “Turn repetitive work into intelligent workflows.”

A production-quality frontend SaaS landing page for **Syntara AI**, a fictional AI workflow automation platform for startups and modern teams.

> **Portfolio Concept Project:**  
> Designed and engineered by **Manoj Kushwaha**.  
> This project is a portfolio concept demonstration of high-end SaaS frontend engineering, clean design systems, responsive layouts, and interactive UI micro-interactions.

---

## 🚀 Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Static Generation)
- **Language:** [TypeScript](https://www.typescriptlang.org/) (Strict typing, zero lint warnings)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Custom warm-white SaaS palette, refined violet-to-blue accents, subtle grid and dot patterns)
- **Animations:** [Framer Motion](https://www.framer.com/motion/) (Restrained, smooth layout transitions, modal reveals, accordion springs)
- **Icons:** [Lucide React](https://lucide.dev/) (Consistent 24px icon system)
- **Micro-Interactions:** Custom canvas confetti triggers, accessible dialog traps, responsive drawer navigation, interactive simulations

## ✨ Features & Sections Included

1. **Sticky Navbar:**
   - Brand mark with pulsing activity indicator
   - Navigation links: `Product`, `Solutions`, `Resources`, `Pricing`
   - Actions: `Log in` and `Get Started` modals
   - Background blur and shadow transitions dynamically on scroll
   - Fully responsive slide-in mobile navigation drawer

2. **Hero Section & Workflow Builder Mockup:**
   - Eyebrow: `AI WORKFLOW AUTOMATION`
   - Headline: *“Turn repetitive work into intelligent workflows.”*
   - Interactive Workflow Builder hero canvas displaying:
     `New Lead Ingestion` → `AI Qualification` → `CRM Update` → `Personalized Outreach` → `Slack Notification`

3. **Trust & Capability Strip:**
   - *“Built for modern teams”*
   - Dedicated capability previews for: `CRM`, `Marketing`, `Support`, `Sales`, `Operations`, `Product`
   - Displays real integration protocols and sample flows without fake company logos or fake testimonials.

4. **Problem & Solution Section:**
   - Headline: *“Your tools shouldn’t create more work.”*
   - Problem cards: *Too many manual steps*, *Scattered tools*, *Repetitive decisions*
   - Interactive *“Without Syntara vs. With Syntara AI”* comparison toggle.

5. **Platform Features:**
   - *Describe workflows in plain English* (with interactive micro-CLI preview)
   - *AI-powered decisions* (with semantic confidence slider & guardrails)
   - *Connect your existing tools* (live integration health matrix)
   - *Monitor everything* (latency waterfall and SLA telemetry)

6. **Interactive Product Showcase:**
   - Full-featured dashboard mockup with canvas, sidebar, inspector, and execution status

     - **Build:** Visual canvas with node palette and parameter inspectors

7. **AI Workflow Generation Section:**
   - Headline: *“Describe it. Syntara builds it.”*

     1. `Understanding request`

## 🛠️ Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm run start
```
